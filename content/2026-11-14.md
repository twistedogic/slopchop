## Kitesurf is now open source

Cloudflare has open-sourced Kitesurf under the Apache 2.0 license, letting developers inspect, modify, run locally, and deploy their own instance of its stateless browser for AI agents. Built entirely on Cloudflare Workers, it parses HTML, applies CSS, executes JavaScript, renders screenshots, and supports the Chrome DevTools Protocol for clients such as Puppeteer, aiming to use fewer resources than Chromium while scaling globally. The repository combines Rust/WebAssembly components such as Blitz for HTML and DOM handling, Stylo for CSS, Boa for JavaScript fallback, Linebender for text and graphics, and Krilla for PDF output. Its main packages are the Engine for sessions and client connections, PageScript for running pages and JavaScript, and PageRenderer for drawing results. The post includes commands for local setup, Puppeteer integration, and deployment; deployment to a personal Cloudflare account requires a Workers Paid plan because Kitesurf uses Dynamic Workers for isolated page contexts. Cloudflare says the project is under heavy development and welcomes focused fixes, tests, reproductions, and documentation corrections.

## Adapting to AI penetration testing orchestrators\: The Modern Security Model

Cloudflare reports a rapid rise in autonomous, LLM-driven penetration-testing orchestrators and argues that traditional defense-in-depth is insufficient without identity-centric containment. It describes more than 50 framework families observed scanning its customers, thousands of source IPs, over 12,000 ARTEX-related repositories, and a roughly 30-fold increase in daily requests since October 1, noting that removing the original ARTEX project appears to have accelerated forks rather than stopped the trend. Cloudforce One incident-response examples show these tools chaining exposed credentials, including static CI/CD tokens, to move laterally between hyperscaler and customer environments; one observed ARTEX intrusion created numerous Workers scripts, generated more than 69 requests per minute, and made 400 database-dump requests in an hour. The article's 'Modern Security Model' has six pillars\: network traffic control and advanced WAF rules for volumetric attacks and scanning; anomaly detection and rate limits for suspicious application behavior; bot-management challenges to distinguish automation from legitimate visitors; identity-gated access and micro-segmentation to protect high-risk systems and contain stolen credentials; schema validation, mTLS, explicit security controls, and default-deny rules for API traffic; and threat intelligence for visibility into emerging campaigns. The central operational lesson is that static secrets, broadly scoped API keys, and internet-reachable administrative or legacy systems are especially dangerous when attackers can automate reconnaissance and exploit chaining.
